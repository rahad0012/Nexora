## 🚀 GitHub থেকে সরাসরি লাইভ করার নিয়মাবলী (Free Live Deployment)

এই প্রজেক্টটি GitHub-এর মাধ্যমে সম্পূর্ণ বিনামূল্যে লাইভ করা সম্ভব। নিচে সবচেয়ে সহজ ৩টি পদ্ধতি দেওয়া হলো:

### পদ্ধতি ১: Vercel দিয়ে লাইভ করা (সবচেয়ে সহজ ও জনপ্রিয় — মাত্র ১ মিনিট)
1. GitHub-এ একটি নতুন Repository বানিয়ে কোডগুলো পুশ করুন।
2. [Vercel.com](https://vercel.com)-এ গিয়ে আপনার GitHub অ্যাকাউন্ট দিয়ে লগইন করুন।
3. **"Add New Project"** এ ক্লিক করে আপনার GitHub রিপোজিটরি সিলেক্ট করুন।
4. Framework Preset হিসেবে **Vite** স্বয়ংক্রিয়ভাবে ডিটেক্ট হবে।
5. **"Deploy"** বাটনে ক্লিক করুন।
6. ১ মিনিটের মধ্যে আপনি একটি লাইভ লিংক পেয়ে যাবেন (যেমন: `nexora.vercel.app`)!

---

### পদ্ধতি ২: GitHub Pages দিয়ে সরাসরি লাইভ করা
1. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেন্যু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Build and deployment** সেকশনের **Source** ড্রপডাউনে:
   - **Deploy from a branch** নির্বাচন করুন।
   - Branch: `main` এবং ফোল্ডার: `/ (root)` সিলেক্ট করে **Save** দিন।
   *(অথবা GitHub Actions সিলেক্ট করে Vite/Static workflow চালু করতে পারেন)*
4. কয়েক সেকেন্ডের মধ্যে আপনার প্রজেক্ট `https://<your-username>.github.io/<repo-name>/` লিংকে লাইভ হয়ে যাবে।

---

### পদ্ধতি ৩: Netlify দিয়ে লাইভ করা
1. [Netlify.com](https://netlify.com)-এ আপনার GitHub দিয়ে সাইন-ইন করুন।
2. **"Add new site" > "Import an existing project" > GitHub** সিলেক্ট করুন।
3. রিপোজিটরি বেছে নিন।
   - Build Command: `npm run build`
   - Publish Directory: `dist`
4. **Deploy Site** ক্লিক করলেই আপনার সাইট লাইভ হয়ে যাবে।

## 🛠 লোকাল মেশিনে রান করার নিয়ম
```bash

npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
